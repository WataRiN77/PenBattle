## 修复：联机模式下旧的选笔 UI 依然常驻

- 现象：接了 `NetworkMatchFlow` 之后，原来的 `MatchSetupManager` 选笔面板还一直挂在屏幕上。
- **根因（我写错了判断时机）**：守卫写的是
  ```csharp
  if (NetworkManager.Singleton != null && NetworkManager.Singleton.IsListening) { enabled = false; return; }

  放在 `Start()` 里。但 `Start()` 在**场景加载时**就跑，那会儿玩家还没点 Host/Client，**`IsListening` 恒为 false** → 守卫从不生效 → 旧流程照跑。

  bool hasNetworkManager = Unity.Netcode.NetworkManager.Singleton != null;

  ```
  `NetworkManager.Singleton` 由它的 `Awake` 赋值，而 `Start` 必在所有 `Awake` 之后 → 可靠。

## ⚠️ NGO 坑：RPC 参数**不支持 `string[]`**

- ILPP 报错原文：`ShowOptionsClientRpc - Don't know how to serialize System.String[]. RPC parameter types must either implement INetworkSerializeByMemcpy or INetworkSerializable...`
- **NGO 的 RPC 参数只接受**：实现了 `INetworkSerializeByMemcpy`（unmanaged 类型）或 `INetworkSerializable` 的类型；**基本类型及其数组**（`int[]` / `ulong[]` 等经 ILPP 通过 ✓）；`string`；`FixedString*`。**`string[]` 不行**（`bool[]` 同理需谨慎）。
  - 佐证：`NetworkMatchFlow.RosterClientRpc(ulong[] clientIds, int[] indices, int chosenMask)` **没有报错** → 数值类型数组是合法的。
- **修复**：把"多条文本"**打包成一个 `string`** 传（选项间 `\n`，名称/描述间 `\t`），客户端 `ParseOptions` 还原；打包前把文案里可能出现的分隔符替换掉，防解析错位。
- **记牢**：以后要传多条文本，一律走**打包字符串**（或 `FixedString512Bytes` / 自定义 `INetworkSerializable` 结构体数组）。

**（步骤③的编辑器指示仍待执行）**：`NetworkTransform` 的 **Scale 同步要打开**（体型强化会改缩放）。

## 步骤④：回合归属 + 输入上报（已写入）

**根因**：客户端 `GameManager.players` 是空的 → `IsMyTurn()` 恒 false → 客户端一支笔都选不中。所以"回合状态下发 + 操作上报"两条腿必须一起做。

**新增 `Assets/Scripts/Net/NetworkMatchSync.cs`**（`NetworkBehaviour`，挂 `NetworkMatchFlow` 同一物体）：
- **A. 回合状态下发**：`NetworkVariable<int>` × 4（round / turn / currentPlayerIndex / phase，Server 写、Everyone 读）。
  **用状态而非一次性 RPC** —— 后加入的端也能立刻拿到当前回合。
- **B. 操作上报**：`LaunchServerRpc(Vector3 dir, float force, Vector3 point)` / `PlaceServerRpc(Vector3 pos)`，都 `RequireOwnership = false`；
  - 用 **`ServerRpcParams.Receive.SenderClientId` 反查玩家**，**不信任客户端自报的 penId**；
  - 校验 `IsMyTurn`，**力度夹紧到 `InputManager.maxLaunchForce`**（防伪造超大力）；
  - 执行时**先发 `InputLaunchEvent` 再 `pen.Launch(...)`** —— 让房主走与单机**完全相同**的被动/结算路径。

**`GameManager`**：
- 新增 `public bool IsAuthority`（房主 / 单机）；
- `IsMyTurn` 分叉：权威端读本地状态，客户端读 `NetworkMatchSync`；
- 新增 `PushTurnState()`，在 `StartNewRound / StartNewTurn / StartTurn / StartResolutionPhase` 中调用；
- 给回合机加闸门（`Update` 计时 / `OnPlayerAction` / `StartResolutionPhase` / `NextTurn` / `StartNewRound`）—— **联机时只有房主推进对局**；
- `PlayerPlacePen`：非权威端改为 `SubmitPlace(...)` 上报。

**`InputManager`**：新增 `IsAuthority` 快捷属性；`LaunchPen()` 在客户端**不本地执行、也刻意不发 `InputLaunchEvent`**（发事件会让客户端也跑回合机），改为 `NetworkMatchSync.SubmitLaunch(...)`。

**`NetworkMatchFlow`**：新增 `TryGetPlayerIndex(ulong clientId, out int playerIndex)`。

**待用户操作**：在 `NetworkMatchFlow` 那个物体上再 Add Component → **`Network Match Sync`**，然后**重新打包客户端**。
