## 18:01 加：碰撞 / 淘汰反馈的「房主广播 → 各端本地播」

**背景（为什么要加）**：客户端两支笔是 kinematic、不跑物理 → 收不到 `OnCollisionEnter`；
且 `PenPenCollisionEvent` **只由 penId 较小的一方发**（防重复）→ **客户端永远收不到碰撞事件** → 客户端完全没有震屏/顿帧。

**设计要点：表现层事件与玩法事件严格分离**（否则客户端会把被动技能重复跑一遍）
- `AllEvents.cs` 末尾新增 region「表现层反馈」，两个**纯表现层**事件：
  - `CollisionFeedbackEvent { point, relativeSpeed, penAId, penBId }`
  - `EliminateFeedbackEvent { penId }`
- `NetworkMatchSync`：`OnNetworkSpawn` 订阅 `PenPenCollisionEvent` / `PenEliminatedEvent`；
  **仅房主**（`IsServer`）→ `[ClientRpc] BroadcastCollisionClientRpc / BroadcastEliminateClientRpc` **广播**，
  同时房主自己也发一次本地表现事件（ClientRpc 不会在本机执行）。
  客户端在 ClientRpc 里发 `CollisionFeedbackEvent` / `EliminateFeedbackEvent`。
- `FeelFeedbackBridge`：改订阅这两个**表现层事件**（不再订阅玩法事件）。
  ⇒ **被动技能（荆棘/点燃/冰冻）仍只订阅 `PenPenCollisionEvent`**，客户端不会重复跑玩法逻辑 —— 这是分层的核心目的。

## 20:34 诊断「笔的运动轨迹不像真实物理」+ PenConfig 参考配置

**从项目文件里查到的两个系统性原因**（先修这两个，光调数值只能掩盖）：
1. `Assets/Resources/Pens/Prefab/笔_1.prefab` 的 **`m_LocalScale = 6000`** ✗
   网格只有 1e-4 量级，靠放大 6000 倍撑到世界尺寸。PhysX 在这种量级下算**惯量张量**与**接触精度**会失真
   → 表现是**旋转不自然、撞完弹开角度怪**。
   修法：把缩放**烘进模型**（FBX 导入 Scale Factor ×6000 或改模型尺寸），让 Transform scale = 1。**世界尺寸不变**，其它逻辑不受影响。
   （已确认：`m_CollisionDetection: 2` = ContinuousDynamic ✓、`m_Interpolate: 1` ✓ —— 这两个本来就设对了）
2. `ProjectSettings/TimeManager.asset` 的 **`Fixed Timestep = 0.02`**（50Hz，默认值）✗
   10 m/s 的笔每步移动 **0.2 世界单位**（≈ 笔长的 1/3）→ 轨迹"台阶化"、接触判定粗糙。
   修法：改 **0.01**（100Hz）；`Maximum Allowed Timestep` 保持 0.333。物理开销翻倍，2~4 支笔无所谓。
3. 另需确认：预制体上有 **CapsuleCollider + BoxCollider 两个碰撞体** —— 重叠碰撞体会产生重复接触，可能导致抖动/诡异弹开。

**PenConfig 参考值（物理推导）**：
`mass 1`（绝对质量对**轨迹**几乎无影响，只影响"同等力度下的速度"）/ `bounciness 0.06` /
**`friction 0.45`**（0.3 偏低 → 滑太远）/ **`linearDrag 0.02`**（这是**空气阻力**、不是桌面摩擦，笔很小应接近 0）/
`angularDrag 0.25` / `maxAngularVelocity 40`（Unity 默认 7 太小）/ `launchForceMultiplier 1` / `maxStatusDurability 100`。

**概念澄清（用户此前混淆过 "friction 当 drag 用"）**：
`Drag` = 空气阻力（与速度成正比、**始终**生效）；`Friction` = 接触摩擦（与正压力成正比、**仅接触时**生效）。
「落地后滑太远」→ 调 `friction`；「飞着飞着就慢」→ 调 `drag`。

**改缩放的代价**：之前的手感基准都是按 6000× 调出来的，改完会变（方向是"更正确"），需要重新微调一次。
