## 编译错修复：`NetworkBehaviour` 的 `NetworkManager` 属性遮住了类型名

- 报错原文：
  ```
  Assets\Scripts\Net\NetworkMatchFlow.cs(54,25): error CS0176:
  Member 'NetworkManager.ServerClientId' cannot be accessed with an instance reference;
  qualify it with a type name instead
  ```
- **根因**：`NetworkBehaviour` 自带一个**实例属性 `NetworkManager`**。在**实例方法**里，这个属性名会**遮蔽类型名 `NetworkManager`**，所以我写的 `NM.ServerClientId` 被解析成"实例访问静态成员" → CS0176。
- **修复**：静态成员必须用**完全限定名** → `Unity.Netcode.NetworkManager.ServerClientId`。
- **记牢（以后在 NetworkBehaviour 子类里常用）**：
  - 凡是要写 `NetworkManager.<静态成员>`（如 `ServerClientId`），**一律加 `Unity.Netcode.` 前缀**。
  - `NetworkManager.Singleton` 在 **static** 成员/属性里没问题 —— 静态上下文取不到那个实例属性，会正常解析成类型。
- 复扫结果：`NetworkMatchFlow.cs` 里其余 `NM.` 调用均为实例成员（`OnClientConnectedCallback` / `OnClientDisconnectCallback` / `LocalClientId`），无同类问题。
