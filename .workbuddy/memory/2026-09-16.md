## 出生点 Bug 排查（指定出生点不生效 + 两支笔重叠）
- 出生链路：MatchSetupManager.CompleteSetup → GameManager.BeginMatch → InitializePlayers(实例化笔) → StartMatch → StartNewRound → foreach PlayerData.ResetForRound → pen.ResetPen(GetSpawnPosition()) → GameManager.GetSpawnPositionFor(playerIndex)。
- GetSpawnPositionFor 逻辑：spawnPoints 有效（非空、playerIndex 在长度内、元素非 null）→ 用指定点；否则**静默**回退到半径圆（spawnRadius、spawnStartAngle、BestRotation 避障）。
- 【发现1·重叠根因】笔预制体 Assets/Resources/Pens/Prefab/笔1.prefab 是 FBX(笔1.fbx) 变体：**根节点 m_LocalPosition 被改成 (-7.48483, 0.5003358, -5.869769)**，而 PenController+Rigidbody+CapsuleCollider+BoxCollider 是加在**子物体**上（代码里 GetComponentInChildren 的注释也印证）。→ Instantiate 后每支笔的根节点都在同一坐标；ResetPen 只移动 PenController 所在子物体，**根节点残留不动 → 多支笔根节点重叠**。
- 【发现2】圆形回退无任何日志/警告，"指定了却没用"无法察觉。
- 场景 SampleScene.unity 里 GameManager.spawnPoints **已配置 4 个点**：SPP1(-20,1,9)、SPP2(20,1,-9)、SPP3(20,1,9)、SPP4(-20,1,-9)（矩形角点，彼此很远）；spawnRadius=10。
- 修复方向：PenController 保存"整支笔的根"（SetSpawnRoot），ResetPen 时**整体平移**（delta 同时作用于根）；GameManager.InitializePlayers 实例化后把根归零并 SetSpawnRoot；GetSpawnPositionFor 回退圆形时 Debug.LogWarning + 打点。
- 交付方式：贴代码给用户自行粘贴（未直接写文件）。
