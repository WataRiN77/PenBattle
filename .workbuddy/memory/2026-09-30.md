## 00:46 修复：房主能控制两支笔（操作权判据错了）

- 现象：**房主一直可以操作两支笔**（跨回合看）。
- 根因：`InputManager.RaycastPen` 里的校验是"**这支笔的主人是不是当前玩家**"：
  ```csharp
  if (gm != null && !gm.IsMyTurn(target.penId)) return false;
  ```
  只校验"主人 == 当前行动者"，**没校验"这支笔是不是我的"** → 轮到客户端时，房主点客户端那支笔也能通过。
- **正确判据：① 笔是我的 ② 现在轮到我的回合，两条同时成立。**
  → 新增 `CanOperate(pen)`（联机 `pen.penId == flow.MyPlayerId && gm.IsMyTurn(MyPlayerId)`；单机无席位概念才回退原来的判断）。
- **同类的"兄弟"bug**：输入层有 3 处用 `gm.GetCurrentPlayerId()`（"当前该行动的人"）—— 在房主上那就是客户端玩家 → **房主替客户端放置 / 放技能**。
  → 新增 `LocalPlayerId()`（联机 = 我的席位，单机 = 当前玩家），替换了 放置 / `BeginSkill` / `ConfirmSkill` 三处。
  （第 336 行还有一处 `GetCurrentPlayerId()`，但走到那里必然是自己的回合 → 等价，保留。）
- **教训（重要）**：**"当前玩家"（该谁动）和"本端玩家"（我是谁）是两个不同概念**，输入层必须用后者。这类 bug **单机永远不会暴露，一联机立刻显形**。
