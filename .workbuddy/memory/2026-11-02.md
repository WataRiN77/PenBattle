## 术语体系确认（用户定义）
技能体系改为**三层并列**，不再是"技能里含效果"：
1. **技能层**：主动技能（玩家回合内主动释放）／被动技能（常时生效、条件触发）
2. **效果层（Status）**：可挂载状态，**独立于技能层**，主动和被动都能挂（燃烧、冰冻）
3. **成长层**：强化（对局中卡牌选择），分通用／专属

用户澄清要点：
- 主动技能**暂不设计**，只留框架（`SkillConfig`/`SkillType`/`SkillSystem` 冻结不删，`SkillType.Burn` 作为"主动挂效果"的模板样例）
- 燃烧**不是技能**，只是效果；`SkillType.Burn` 和 `IgnitePassive` 都是它的施加来源
- 强化定义里的"对局中"**包含开局强化**（现有 `UpgradePhaseManager` 注释"开局/败者共用"符合）
- 专属强化条目偏薄（每支笔 1~2 条），用户会自己补设计

## 落地：粘液被动（#4，用户拍板的规则）
**规则**：层数每回合减半（向下取整）＝同燃烧；减速**递减**且**上限 50%**。

**曲线**：`reduction = maxSlow * n / (n + softness)`，`speedMultiplier = 1 - reduction`
- `maxSlow = 0.5`、`softness = 1.5` 为默认
- 天然封顶（n→∞ 逼近但不超过 50%），边际收益递减
- 数值：1层80%、3层66.7%、6层60%、10层56.5%

**实现文件**：
- 新建 `Status/AllStatus/SlimeEffect.cs`：`stacks` + `maxSlow` + `softness`，`duration=0` 走层数驱动，`OnTick` 里 `stacks /= 2`
- 新建 `Skills/Passive/SlimePassive.cs`：`OnHitPen` → `PenStatus.ApplySlime(opponent, stacks, maxSlow)`
- `Status/PenStatus.cs` 加 `ApplySlime(target, stacks, maxSlow=0.5f)`（第三个效果走门面）
- `Config/PassiveSkillEntry.cs`：枚举末尾加 `Slime`（**=7**，PenCfg 里 effect 填 7），补 GetName/Describe/GetValueLabel/GetValue2Label
- `Skills/Passive/PassiveSkillManager.cs`：加工厂 case

**关键取舍**：只改 `PenController.slowMultiplier`（`Launch` 里已乘它），**不碰 `_rb.drag`**
- 原因：drag 会被 `RestoreBaseValues()` 和 `ApplyConfig()` 重写，与顺滑被动/强化系统抢参数
- 代价：已飞在空中的笔不会被"黏住"，只影响下一次发射
- 注意：`slowMultiplier` 目前是**独占通道**，将来多来源减速要改成乘算栈
