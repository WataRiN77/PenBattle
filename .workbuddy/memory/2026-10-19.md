**踩坑（重要，下次直接复用）**
1. **`paint-order: stroke fill` 在 HTML 文字上不生效** → 用 `-webkit-text-stroke` 会把描边画在字形内部，留下白色细缝（看起来像重影）。
   **解法**：写一个 JS 克隆 `.tit` 内容成 `span.stroke`，`position:absolute;inset:0;z-index:-1;color:transparent`，给它上 `-webkit-text-stroke`，父级文字（白/黄填充）画在上层盖住内半边 → 得到干净的外轮廓。
2. **`stroke-linejoin: round` 对 `-webkit-text-stroke` 有效** —— 不加的话 CJK 锐角收笔会冒出尖刺。
3. **描边别超过字号 12%**：15px/82px 时字内空间（如「口」的洞）会被吃满。9px/82px ≈ 11% 刚好。
4. **别叠加半透明大偏移 text-shadow**，会和描边混出灰雾第二层重影；要立体感就用同色的实心小偏移（6px）。
5. `+media-insert` 之外，**Chrome 无头导出仍是 `?only=N` + `--force-device-scale-factor=1`**，虚拟时间 7000ms 保证 Google Fonts 加载完。

**排版校验方法**：每张导出后目视检查底部 CTA 是否压住内容。经验值：`.wrap` padding-top 82 / padding-bottom 184，卡片 padding 14+字号20，一段内容（tag+3卡）约 330px。
