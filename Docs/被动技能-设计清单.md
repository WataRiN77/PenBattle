## 一、术语（全项目统一，务必沿用）

| 术语 | 含义 | 代码对应 |
|---|---|---|
| **小局** Round | 从开局直到只剩一名玩家存活 | `RoundStartEvent` / `RoundEndEvent` / `_roundNumber` |
| **回合** Turn | 小局内每位存活玩家各行动一次 | `TurnStartedEvent` / `TurnEndedEvent` / `_turnNumber` |
| **行动** Action | 单个玩家的一次操作（弹笔 / 放置 / 使用技能） | `ActionStartedEvent` / `ActionEndedEvent` |

## 三、待实现（原始设计 → 实现要点）

### 4. 粘液
> 笔具有一定粘性，撞击笔时对其施加粘液；粘液会使笔减速，层数越高效果越强。

- **实现要点**：本质是"燃烧的层数机制 + 冰冻的减速效果"的结合体 → 新建 `SlimeEffect : StatusEffect`，带 `stacks`，回合结束时**不扣耐久**，只按层数提高 `drag`/降低 `speedMultiplier`（层数越高越强），层数按某种规则衰减（建议每回合 −1 或减半，待定）。
- **参数**：`value`=每次叠加层数，`value2`=每层减速强度。
- **视觉**：可复用冰冻的思路（`FreezeVisual` 的"复制网格 + 叠加层"），换一个绿色的黏液 shader（注意 **shader 必须纯 ASCII**）。
- **触发**：`OnHitPen`。

### 5. 双笔
> 开局时拥有 2 支笔，但每回合只能操作其中 1 支。

- **实现要点**：需要**改动核心回合结构**——`PlayerData` 从"1 支笔"变成"多支笔"，`GameManager` 行动时要指定"操作哪一支"，`InputManager` 需要笔的切换逻辑，淘汰判定变成"该玩家所有笔都出界才算淘汰"。
- **这是改动量最大的一个**，建议放在最后做，且要先想清楚回合流程（每回合是指挥一支还是一支一次）。
- **触发**：开局（`OnRoundStart` / 初始化）。

### 6. 幽灵
> 获得一支处于"前一回合状态"的幽灵笔，它每回合结束时会复制你上一回合的行动。

- **实现要点**：需要**记录每位玩家上一回合的行动**（发射方向/力度 或 放置位置），并在回合结束时把同样的行动重放给幽灵笔。
- **数据结构**：在 `PlayerData` 里加"上一回合行动"的记录（类型 + 方向 + 力度 / 位置），在 `ActionEndedEvent` 时写入。
- **触发**：`OnTurnEnded`（回合结束）。

### 7. 自动回复
> 每回合结束时自动回复一定耐久。

- **实现要点**：`PenController` 需要新增"回复耐久"的公开方法（例如 `RestoreStatusDurability(float)`，还没做）。
- **触发**：`OnTurnEnded`。
- **注意**：耐久每小局会被 `ResetForRound` 重置满，所以这个被动只在"同一个小局内跨回合"有意义。

### 8. 涅槃
> 死亡时可在任意位置复活（每局 1 次）。

- **实现要点**：监听 `PenEliminatedEvent`（`OnEliminated`），若没用过 → 取消淘汰（要让 `GameManager` 支持"撤回淘汰"）→ 进入一个"选位置"的交互（类似 `InputManager` 的放置模式）→ 复活。
- **需要**：`GameManager` 提供"取消淘汰"的接口；`InputManager` 增加一种"复活选点"模式。
- **触发**：`OnEliminated`。

### 9. 潜行
> 开局时你的笔具有潜行：没有碰撞体积，直到你主动撞击其他笔或耐久降低。

- **实现要点**：开局把笔的 `Collider.enabled = false`（或 `isTrigger`），监听 `ActionEndedEvent`（自己主动发射）或 `PenDamagedEvent`（耐久降低）→ 解除潜行。
- **注意**：没有碰撞体积时笔会掉下桌子 → 需要同时冻结重力或 `isKinematic`，直到解除。
- **触发**：`OnRoundStart` + `OnActionEnded` / `OnDamaged`。

### 10. 陀螺
> 这支笔会不断地自转。

- **实现要点**：最简单位是常驻力矩：`rb.AddTorque(axis * value, ForceMode.Acceleration)`（在 `FixedUpdate` 里）或直接设 `rb.angularVelocity`。
- **实现方式**：给 `PenController` 加一个"常驻自转"参数，或者做一个带 `FixedUpdate` 的被动组件。
- **参数**：`value`=自转速度。
- **触发**：常驻（`ApplyStaticEffect`）。

### 11. 钢笔
> 这支笔运动时会从笔尖撒出墨水；其他玩家弹射沾有墨水的笔时，墨水会遮蔽玩家的视野。

- **实现要点**：两部分——
  1. **撒墨**：笔移动时在笔尖生成墨水痕迹（可用 `TrailRenderer` 或地面贴花），需要一个墨水 shader / 材质。
  2. **遮视野**：沾墨的笔被弹射时给**该玩家**加一个屏幕遮挡效果（UI 层贴一张墨水贴图，或后处理）。
- **需要**：屏幕遮罩的 UI 组件 + 墨水纹理（**需要贴图**）。
- **触发**：常驻（撒墨）+ `OnLaunch`（遮视野，且要判断"这支笔是否沾过墨"）。

## 五、可用的被动钩子

```csharp
OnRoundStart()                    // 小局开始        → RoundStartEvent
OnTurnStarted()                   // 回合开始        → TurnStartedEvent
OnTurnEnded()                     // 回合结束        → TurnEndedEvent
OnLaunch()                        // 自己发射前      → InputLaunchEvent（已保证在 Launch 之前）
OnActionEnded()                   // 自己的行动结束   → ActionEndedEvent
OnHitPen(PenPenCollisionEvent e)  // 笔-笔碰撞（e.initiatorPenId 是主动撞击方）
OnDamaged(PenDamagedEvent e)      // 受到耐久伤害
OnEliminated()                    // 被淘汰
ApplyStaticEffect()               // 常驻效果（Bind 时调用一次）
```

工具方法：`FindPen(penId)`、`FindOpponent(e)`、`IsMe(penId)`；字段 `entry`（含 `value` / `value2`）。

## 六、踩过的坑（写新被动时注意）

1. **`.shader` 文件必须纯 ASCII**（注释也别写中文）——中文 Windows 上 Unity 的 shader 编译器可能按 GBK 解码 UTF-8 文件，导致编译失败（表现为紫红色）。
2. **叠加层/视觉网格要 `SetParent(源物体, false)` + 只设 local TRS**，不要用 `src.transform.parent`（对象在根节点时 parent 为 null，视觉会脱离跟随）。
3. **alpha 不要用硬阈值**（`smoothstep(阈值, 1, 值)`）——两个噪声相乘后平均值很小，会被裁成全透明。用"乘法 + 提亮系数 + 对比曲线"。
4. **花纹优先用物体空间坐标**，不要依赖 UV——模型某些网格的 UV 可能退化成一个点，花纹会变成常数而看不见。
5. **细长物体上的花纹要做各向异性**（沿长度拉伸），否则纵向会密到像噪点。
6. **数值由施加方显式传入**（如 `effect.Freeze(target, factor, turns)`），不要放在 `OnApply` 里——`AddComponent` 时 `OnApply` 比"设置数值"更早执行。
7. **重复施加**：`StatusEffectManager.AddEffect<T>` 会复用已有组件（不是为了重建），需要刷新时自己在组件上写 `Reapply/Refresh` 方法。
8. **DOT/状态效果每小局清零**：`StatusEffectManager.ClearAllEffects` 已在 `PlayerData.ResetForRound` 里调用，新状态效果自动适用。
