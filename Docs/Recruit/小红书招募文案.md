**正文**

一个人做毕设的独立开发者来报到👋
游戏叫《弹笔大战》——课桌上的多人派对物理对战。

就是把上学时偷偷玩的那种「弹笔」，做成四个人能一起打的 3D 游戏。
弹弓式蓄力，把你的笔甩出去，一次次把对手撞下桌面。

🎯 **核心玩法**
· 弹弓蓄力，把对手的笔弹出桌面
· 每回合败者选强化，自由组合流派
· 先积 3 分者获胜

✅ **现在到哪一步了**
玩法逻辑、回合制、物理手感、技能与被动、地图系统、联机框架，全都在跑，已经能完整打一局。
缺的是「看起来像个游戏」的那部分——美术、UI、声音。

👀 **想找三个人**

1️⃣ **3D 建模**
笔的不同造型与配色 / 桌面场景与地图 / 可破坏障碍物 / 简单的小小人形

2️⃣ **平面美术**
卡牌插画（强化卡面、技能图标）/ 流派图标（火、冰、冲击波）/ UI 元素（按钮、面板、血条）

3️⃣ **音乐音效**
BGM 与输赢反馈音 / 撞击、冰冻、UI 交互等情境音效

🎨 **风格参考**
卡通低模、高饱和、派对感
美术参考《胡闹厨房》《人类一败涂地》
声音参考 Tricky Towers、Slay the Spire、It Takes Two

🎁 **你能得到**
· 一款真正发布上线的 3D 多人游戏
· 能写进作品集的完整项目，不是半成品 demo
· 正式署名 + 参赛共同署名

🌐 **合作方式**
可远程，每周 4~5 小时，一起把它做完。
计划 2027 上半年完成。不急，但要收尾。

💬 **欢迎私信交流**

## 四、发布小贴士

- **首图文字别太多**：封面已是对撞大图 + 3 行信息，够了。别再往上贴红字。
- **正文前 2 行最关键**：手机端折叠前只显示约 3 行，「一个人做毕设的独立开发者来报到」这句就是留人的钩子。
- **别写「无偿」也别写「有偿」**：写了「无偿」会掉一半点击，写了「有偿」会招来一堆练手的。等私信聊上了再说。
- **标签别超 12 个**：超了系统会降权。
- **发完 1 小时内回复评论**：前 1 小时的互动决定初始推荐量。
- **可补一张「进度截图」当第 2 图**：真机运行画面比设计图更能证明「不是空想」，可惜目前素材是 AI 概念图，建议跑一局截个真机图替换。
